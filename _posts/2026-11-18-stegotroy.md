StegoTroy hides file inside images using least significant bit encoding,
compare original and encoded image to show which pixels changed,
and also check file metadata. It is built with Python and Streamlit.

Source: [github.com/cassoftroy/StegoTroy](https://github.com/cassoftroy/StegoTroy)
